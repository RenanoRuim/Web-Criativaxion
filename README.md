# 🚀 Web Criativaxion — NPA 2026

Um projeto web interativo e moderno desenvolvido por alunos do curso de Programação de Jogos Digitais da ETEC Cícero Dias para o NPA 2026 (Nave Portas Abertas).

## 📌 Sobre o Projeto

O Web Criativaxion é uma aplicação web de página única (Single Page Application) desenvolvida como parte de uma oficina escolar de introdução ao desenvolvimento web. O objetivo principal do evento é abrir as portas da escola para a comunidade e demonstrar de forma lúdica, visual e prática a importância do design, da criatividade e da programação.

O site conta com um recurso interativo especial: um botão de alternância de CSS. Com ele, os visitantes podem desativar os estilos em tempo real para entender visualmente o que é um site puramente em HTML estruturado versus uma página estilizada.

* ✨ Funcionalidades Principais

* 🔄 Alternador de Estilos (CSS Toggle): Um script em JavaScript que ativa e desativa dinamicamente as folhas de estilo da página para fins educacionais.

* 📂 Visualizador de Código Embutido: Permite aos usuários alternar entre a visualização do código-fonte (HTML, CSS e JS) diretamente na página através de requisições assíncronas (fetch).

* 🎠 Carrossel Infinito Animado: Seção interativa destacando os integrantes da equipe com animações fluidas em CSS.

* 🎨 Design Cyberpunk / Arcade: Utilização de fontes estilizadas (Audiowide e Press Start 2P), gradientes personalizados, efeitos de desfoque (backdrop-filter) e sombras dinâmicas.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias web fundamentais, sem o uso de frameworks complexos, demonstrando domínio puro da base:

HTML5: Estruturação semântica de todo o conteúdo.

CSS3: Estilização avançada, Flexbox, animações personalizadas e variáveis visuais.

JavaScript (ES6+): Manipulação do DOM, eventos de clique e carregamento assíncrono de arquivos via API fetch.

Google Fonts: Tipografias personalizadas (Audiowide e Press Start 2P).
